# RSS Dashboard 2.7.0

This release adds a short in-plugin release summary, and it rounds out the Inoreader starred-article import that landed earlier in the 2.x line.

## A release summary where you already are

![RSS Dashboard logo](https://raw.githubusercontent.com/amatya-aditya/obsidian-rss-dashboard/master/assets/branding/logo.png)

RSS Dashboard now shows a short summary the first time you open the dashboard after a major or minor update. It only appears once per release line, never for bug-fix releases, and you can reopen it any time from **Settings → About → What's new in v2.7.0?**. Clicking the image opens it in the same full-screen viewer the reader uses.

## Also improved

- Import starred articles from Inoreader, with labels kept as tags and a re-import that updates existing articles instead of duplicating them.
- Legacy JSON and Shard storage v1 are now formally deprecated: the storage prompt names the 3.0 cutoff and offers **Skip this version** instead of a permanent dismissal.
- Settings → Storage reports the resolved metadata path and any leftover `user-state.json`, so it's clearer where your data actually lives.
- Saved-article templates gained `{{saveDate}}`, `{{saveTime12}}`, `{{saveTime24}}`, and `{{firstSeen}}`.
