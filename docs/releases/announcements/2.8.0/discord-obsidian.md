# RSS Dashboard 2.8.0 — Obsidian Discord

- Prepared: 2026-11-05
- Platform: Obsidian Discord
- Release: 2.8.0

---

**RSS Dashboard 2.8.0 is now available!**

This release contains many new features and improvements and turns several RSS Dashboard workflows that used to require extra steps into things you can do right inside Obsidian.

For anyone unfamiliar with it, RSS Dashboard is a free, open-source RSS reader built directly inside Obsidian.

- Read RSS content while the full article loads in the background, then switch versions right inside the Reader without ever having to leave Obsidian.
- Saved-note templates now allow you to edit templates independently, choose a default, assign templates per feed, and configure folders and filename patterns. Choose whether a template saves RSS or fetched content, and use `{{contentSource}}` to record which version was saved.
- Card image covers can now be fetched directly from the source article and missing card images can be replaced if the site offers one. A new button to fetch and replace images has been added directly to each card, and a 'fetch all card images' button has been added to the dashboard toolbar.
- Tags: You can now customize the tag text color or select from a collection of predefined theme colors.
- Podcasts: Chapter markers have been added to the playbar for episodes that ship with timestamps, and a preview sleep-timer progress has been added.
- Play Twitch VODs and live channels, plus YouTube embeds, in the Reader. **Video Focus mode** works with Twitch and YouTube.
- Set global tag colors, swipe between panels on mobile, and adjust article title size.
- Faster startup, immediate article-state updates, more reliable syncing, and expanded keyboard and screen-reader support.

Available now through Obsidian Community Plugins and our release page.
