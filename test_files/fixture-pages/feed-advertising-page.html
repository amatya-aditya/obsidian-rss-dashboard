Fixture page that advertises a feed

This page is not a feed. It stands in for a site's landing page, served from this repository so the Add feed and Edit feed dialogs' Load can be checked against a page address whose feed the plugin has to discover.

Powered by WordPress, so the Save path reaches the same feed through the plugin's WordPress fallback as well, and Load and Save agree on the address.

The advertised feed is the fixture server's synthesized /user-agent-feed.xml, linked above as a relative address so it resolves to whichever host and port serves this page.
