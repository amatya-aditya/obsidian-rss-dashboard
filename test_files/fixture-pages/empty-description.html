Fixture article with no feed description

This page stands in for a real article whose feed ships an empty description, content, and summary. The fixture vault's matching article links here, so the Reader's fetch-on-open has a page to read.

The body is deliberately plain: paragraphs of ordinary prose with no headings, lists, images, or scripts, so Readability extracts a straightforward article and the page metadata is read from the document head before that extraction runs.

Because the feed supplied no text, the article card's preview stays blank until the Reader fetches this page. Once the fetch succeeds, the Reader stores the description above and the card shows it, which is the behaviour this fixture exists to exercise without any server outside the repository.

Serving this page is all the fixture server does. It keeps the scenario reproducible from a fresh worktree, a second machine, or CI, where a hand-edited working copy and a page on an unlisted port are not available.
